# 绘本创作工作室

交付与用户约定的完整绘本。规划、提示词、试画和插图各有自己的完成状态，不能称为已成书。以读者能理解的故事、可信的连续画面和实际可读的页面作为质量依据。

本技能独立工作：已整合四个上游项目的有用方法，不要求安装它们，不联网加载未核验的上游指令。方法来源与适配边界见 [sources.md](references/sources.md)。

## 先识别当前任务

- **新书**：确认尚缺的关键要求，完成全书脚本、视觉定稿、插画、排版与验收。
- **续作**：先读现有 `book.json`，运行状态检查，恢复缺失、过期或待审页面，沿用已确认设定。
- **修改**：先定位文本、视觉、剧情、排版中哪层发生变化，按依赖关系修订，保留已采用版本。
- **审校**：只读审看约定的完整作品，逐页定位问题并区分技术错误、图文偏差和设计提升；用户要求修改后才进入修订。
- **质量升级或市场对标**：读 [editorial-and-benchmark.md](references/editorial-and-benchmark.md)，先核验作品与参考资料的阅读范围，再把可见优点转成该书自己的角色行为、图画信息和页面节奏；不能只更新分数或提示词。
- **仅方案或仅分镜**：按用户指定范围完成，不调用生图、不自动扩成制作任务。

遇到未决的年龄、页数、语言、用途、主角、画风和成书格式，集中询问。已有要求和已授权的自主决策不重复确认。不要把固定 12 页、预置角色、三语或满版构图当成普遍默认。

## 工具与工作位置

- 正式出图需要当前环境真实可调用的图像生成工具；采用原生 `image_gen` 或已获授权的等效工具。技能本身不包含图像模型。
- 参考图必须先查看，再附带到支持图像参考的生成调用。记录实际使用的工具和参考资料；不把文字提示当作已传入参考图。
- 项目数据和中间素材在用户工作区内；遵守当前环境的中间文件与交付目录约定。用户已有项目就在原项目续作，不另起同名副本。
- 不自行启动开发服务。离线 HTML 可直接打开。需要 PDF 时使用本技能排版工具，或按用户的明确复杂版式要求使用当前可用的排版工具。
- 缺少生图、字体、PDF依赖或导出能力时，准确指出缺口并保存已完成内容；缺口解决前不能标记整书完成，也不能用程序画的占位图替代真正插画。

## 全书制作流程

### 1. 统一创作要求

确认读者年龄与阅读方式、主题与情绪、页数口径、主角、语言、单页/跨页构图、画幅、使用用途和交付格式。正文页数与封面、封底、扉页等附加页分别记录。涉及印刷时采用用户或印刷方给出的尺寸、出血和装订要求。

预算、生成重试边界和自主决策范围按用户约定记录。保留完整目标，不以样页取代全书交付。

创建项目数据前读 [project-contract.md](references/project-contract.md)。项目数据是唯一生效版本；各辅助审校只提出建议，不各自生成另一套故事。

### 2. 写完故事与逐页计划

读 [story-and-language.md](references/story-and-language.md)。建立主角愿望、阻碍、行动、转折与结尾；先写完全部页面，再检查节奏、因果和可朗读性。

每页明确叙事目的、正文、动作、情绪、视觉证据、角色和场景、道具前后状态及画面依赖。图像必须承担叙事，不能用长说明解释没有画出的事件。

定稿时同时检查全书镜头安排与翻页期待。相邻页构图重复应服务于等待、重复或渐变的叙事目的；关键动作和情绪转折需要足够清楚的观看距离，不能只靠替换正文推动同一张合影。

高质量修订同时检查图画有没有增加正文未说出的信息、配角是否有自己的反应与行动、结尾是否通过行为或道具兑现前文。角色辨识不能只靠更换围巾颜色，装饰细节不能代替叙事细节。

需要拼音、英文或知识内容时，按已定稿正文做专项审校。未要求的语言和教育目标不额外添加。涉及可能错误的现实知识时使用可靠来源核验，不能让故事规则掩盖知识错误。

### 3. 建立视觉与连续性基准

读 [visual-direction.md](references/visual-direction.md)。提出与故事有关的视觉选择，合成一套画材、轮廓、配色、明暗、背景复杂度与留白规则。以明确可见特征描述风格，避免只写“高级、治愈、可爱”。

建立原创角色设定图、关键场景和道具参考。分别标识风格参考、身份参考和场景参考的用途。全书所有页面显式沿用已采用视觉设定；剧情允许的变化单独记录。

选择能覆盖本书实际难点的代表页完成实图校准；包括需要验证的角色互动、道具操作或场景切换。校准后完成余下全书，不把试画当最终成果。用户要求直接完成且授权自主选择时，在授权内进行校准和检查，不额外增加逐页审批。

使用指定文字区域时，生图前用实际字体执行 `bookcheck.py --stage ready --font 字体路径`，一次测量全书正文；先调整不够用的框，再冻结留白提示。机器预检不判断背景与文字的视觉对比，最终仍要看实际页面。

把代表页放回相邻页序列检查，确认近远、焦点和情绪变化在实际画面中成立；画风统一与镜头重复分别判断。封面的主图、书名层级和留白关系单独设计，不沿用正文排版就视为封面完成。

### 4. 逐页生成并审查

读 [production-and-review.md](references/production-and-review.md)。完成每页 `prompt` 后运行 `bookcheck.py --stage ready`，解决错误再正式生成。

最终提示词由页计划、固定角色特征、动作与肢体关系、道具状态、明确的视觉规则、参考图用途、文字区域及禁止意外出现的元素组成。角色、场景、风格说明不能互相抵消。

默认生成无正文插画；书名、正文、拼音和英文由确定性排版放入。用户明确要求画中短文字时，逐字核验且保留可修正路线。

按页面视觉依赖顺序生成。独立页面可在基准冻结后并行；共享素材和主项目数据由一个负责人合并。生成结果记录为新版本，在看图通过后才设为当前采用版本。

取得真实图片后计算当前输入签名和图片摘要，结合实际看图填写 `qa`。工具输出、文件存在和图像尺寸都不是视觉验收通过的证据。

对正文点名的接触动作、形状和数量放大检查准确位置，再回到正常阅读大小确认孩子看得清楚。相似动作不能替代实际动作；具体视觉证据不足时保留待修状态，不用笼统的“角色正确、画面好看”通过 `text_match`。

### 5. 排版与成书

读 [layout-and-delivery.md](references/layout-and-delivery.md)。先运行 `bookcheck.py --stage complete`，再导出全书。内置工具提供保留整幅插图、独立正文区、可选逐字拼音及英文的离线 HTML 与阅读版 PDF。每个版本输出到新目录。

对艺术化文字区、跨页延展、印刷生产文件等需求，保留同一项目数据，按用户规格制作相应版式，不强塞进内置单页模板。

内置 `positioned` 可指定完整插画与文字的安全区域，`image-only` 可制作真实无字页；需要文字进入画面留白时，先在图画计划中设计留白，再实际核对，而不是事后把文字盖到角色上。窄屏展开图文，打印保留设计位置。

检查全部页面和整书缩略图，再顺序阅读全书。PDF 必须实际打开或渲染检查；可用工具仅抽取文本时，不能声称已完成视觉验证。

阅读 HTML 分别检查窄屏和桌面；使用页面 `presentation` 设置标题层级、正文位置和对齐，修改纯排版不必重画插图。全书复核同时给出技术可读性与创作质量的具体依据，检查器的 `approved` 仅表示版本和验收记录匹配。

### 6. 修改与恢复

读 [revision-and-evaluation.md](references/revision-and-evaluation.md)。只改文字且不改画面含义时可复用插画；改动作、人物或道具时同步修改视觉依据，签名会标记相关页面过期。前置页面变化传播到依赖它的页面。

批量重绘前先区分本页问题与全局设定问题。遵守已确认的重试边界；反复失败时说明实际失败原因与可选择的修正方向，不无限抽图、不默默删剧情。

## 命令使用

以下命令在技能目录运行；`book.json` 换成真实项目文件，目标目录须为新目录。Python 可使用环境已经提供的运行时。

```text
python scripts/bookcheck.py 项目目录/book.json --stage draft --status
python scripts/bookcheck.py 项目目录/book.json --stage ready
python scripts/bookcheck.py 项目目录/book.json --stage complete
python scripts/render_book.py 项目目录/book.json --output 新的交付目录
python scripts/render_book.py 项目目录/book.json --output 新的交付目录 --pdf --font 已验证字体文件
```

检查器只读项目数据并输出 JSON，不能自动确认用户决定或自动通过视觉审查。排版工具只写明确的全新交付目录。依赖与详细参数以工具 `--help` 和 [layout-and-delivery.md](references/layout-and-delivery.md) 为准。

## 完成口径

只有全部约定页面的实际图片、正文、语言层、版式与交付文件均完成并验收，才报告整书完成。高质量目标还需实际核对封面层级、图文精度和整书节奏；未解决的问题应逐项说明，不能以文件齐全、全绿状态或测试覆盖率代替。简要提供可打开的成书、可编辑文件、素材位置和仍存在的真实限制。不要额外生成与创作无关的总结文档。
