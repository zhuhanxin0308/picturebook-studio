# 出图、验收与制作控制

正式生图和填写图片验收时读取。

## 提示词编排

由项目数据组织最终提示词，不让几个技能轮流改写同一页面。逐项覆盖：

1. 页码、读者年龄、画幅、叙事焦点。
2. 出场角色的固定特征、本页动作、眼神和情绪；多角色分别描述。
3. 场景、镜头、可见锚点与关键道具状态。
4. 正文对应的视觉证据，不能只写模糊故事摘要。
5. 画材、笔触、色彩、背景程度、文字留白位置。
6. 每个参考素材的用途，哪些特征保持、哪些允许变化。
7. 本页实际需要的手脚、遮挡和物体关系约束；按角色物种和画面可见范围说明，不能对所有动物套“只有两只手”。
8. 插画中的文字策略以及需避免的具体错误。

封面与正文默认无字出图，标题后期排版。若用户明确选择图中文字，限制到已确认的实际短文字，并逐字检查；不要让生图模型自行升华正文。

## 执行与进度

生成前检查输入和参考图，记录当前 `page_fingerprint`。生成后将真实输出保存在项目内的新文件，记录 `image.path` 与生成时的签名。不要将之后变更的签名回填到旧图，冒充用新输入生成。

生成前把页 ID、当前输入签名、最终提示词及实际参考路径保存到工作区可恢复的生成记录，不只在会话里打印。图片落盘后先补记真实输出路径和摘要，再审图写 `qa`。中断恢复时对照这份记录与实际文件；已有图片但没有可信生成前记录时，不把恢复后计算的签名当作旧生成依据，保留候选并重新完成可追溯的生成。

Windows 上把中文提示词从命令行交给编排工具时，明确核验管道编码。无法确认编码时，输出使用 `json.dumps` 默认的 ASCII Unicode 转义，再在编排层 `JSON.parse` 还原；把还原后的实际提示与项目原文对照后才调用生图。乱码、截断或字句不一致属于输入失败，候选应隔离并记录实际发送的内容，不按正确原文回填成功验收。

先处理存在视觉依赖的前置页，再处理后续页。只有各页输入已经冻结、参考素材已验证且相互独立时才并行；不同工作人员不得同时修改主 `book.json`。

避免重复生成已有合格页面。调用失败、工具返回结果不明或图片未落盘时，先核对真实结果，再决定重试。重试次数、费用和时间边界按项目约定，不擅自无限扩大。

## 六项视觉验收

使用画中留白或连续小画面时，将文字位置和每个小画面的时间关系写进正式输入。明确哪些角色是在不同时刻重复出现，逐格检查肢体与道具，再看完整阅读方向；不能将所有格的角色数相加后误判成多余人物。留白图先与实际文字矩形对照，不以“大概空着”通过构图验收。

每页实际打开图片，并和正文、角色基准及必要的前后页对照：

| 验收键 | 需要观察的事实 |
| --- | --- |
| `identity` | 角色身份、物种、年龄感、轮廓、服装和关键标记正确 |
| `continuity` | 场景空间、道具持有人、位置、数量和状态延续合理 |
| `text_match` | 正文描述的关键动作与事物有可见证据 |
| `anatomy` | 肢体、手脚、遮挡、与物体接触关系符合角色设定 |
| `style` | 画材、轮廓、色彩和细节程度属于全书视觉规范 |
| `composition` | 叙事焦点清楚、文字区域可用、没有关键主体意外裁切 |

`qa.reviewer` 记录实际审查者；`notes` 写本页的具体观察、修复结果或不适用原因，不能只写“已通过”。`qa.image_sha256` 绑定被审查的真实文件，`qa.input_fingerprint` 绑定对应输入。

对“捏住角、压平、递交、圆顶”等正文中的精确表述，放大确认接触点、物体变形、持有人或形状确实出现，再以实际成书大小判断可辨性。爪碰到布料不一定是捏住指定角，靠近物件不一定是已经转交；证据不足应修图或在授权范围内先修页计划，不能含糊通过。正常近景的身体出画不等同于意外断肢，检查实际可见范围与动作完整性。

这些记录证明审查针对哪个版本，不证明人的判断一定正确。不得运行程序自动给全部字段打勾。颜色、文本等机械检查可以辅助，不能替代图像阅读。

## 整书复核

将已采用图片做缩略图总览，检查画风、主角和页面密度；顺序阅读检查因果、情绪、动作方向和场景切换；对照道具状态检查拿起、放下、转交和损坏过程。

另检查封面是否建立书名与主图层级、关键转折是否在画面中产生可见变化、重复构图是否具有叙事作用。区分可定位的图文错误与有依据的设计建议，不把“必须满版、必须跨页”作为统一标准。高质量目标或修订已有漏检问题时，用独立审校重新看实际成书，并对有争议的具体页放大复核；不能只读取旧 `qa` 再次宣告通过。

发现图文不一致时定位原因：图片漏画则修图，页计划不可能表现则先修计划；涉及已确认情节的改变由用户决定。不能为了保留漂亮图片默默改掉关键剧情。
