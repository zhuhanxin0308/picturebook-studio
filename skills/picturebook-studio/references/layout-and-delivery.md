# 排版、导出与交付

准备成书排版时读取；印刷或复杂跨页另按用户的实际规格处理。

## 确定输出

确认屏幕阅读或印刷用途、最终文件类型和单页尺寸。内置排版工具制作阅读版，提供完整插图与独立正文区；标题、正文和所选语言层都来自项目数据。

需要艺术化留白、文字环绕或跨页延展时，在生图前决定构图与文字区域，使用能够实现该版式的工具制作，并沿用相同正文、页面顺序和验收规则。不要生成满版图后再强行裁切人物腾出文字区。

## 运行环境

检查器和 HTML 导出使用 Python 标准库。PDF 导出另需 `reportlab` 与 `Pillow`；优先使用当前环境提供的运行时和已有依赖。需要安装缺失依赖时，遵守用户的安装与网络约定，使用项目内环境，勿静默改动系统环境。

PDF 命令需要显式字体文件；建议采用覆盖中文、声调拼音和英文的 TrueType 字体。实际支持以字体解析与字符覆盖检查为准。不能因为系统有某字体名称就假定该文件存在，不能用缺字方框代替字符。

```text
python scripts/render_book.py 实际项目/book.json --output 新的交付目录 --pdf --font 实际字体路径
```

输出目录必须不存在；发生错误时保留原项目，工具清理自己的暂存目录，不把半本文件当成完整成品。已有成书版本不得覆盖，换一个明确的新版本目录。

## 排版原则

以正文可读性决定文字区和字号。内置模板保留图片比例，不拉伸、不裁剪图像；文字区独立于插画。字号、文字位置、纸色和字色可依叙事需要在每页 `presentation` 中明确配置，尺寸、边距、行距和图区大小沿用全书 `format`。

封面默认上方标题、居中、正文基准字号的 1.5 倍；正文默认上图下文、左对齐；封底默认上图下文、居中。可覆盖 `layout` 为 `image-top`、`text-top` 或 `title-top`，`text_align` 为 `left` 或 `center`，`font_size_pt` 为正的有限数值，颜色为六位十六进制。示例：

```json
"presentation": {
  "layout": "title-top",
  "text_align": "center",
  "font_size_pt": 42,
  "text_color": "#315A6F",
  "paper_color": "#FFFAEF"
}
```

标题层级服务于该书实际内容，不能把不同书名、封面或转折页继续套成同一效果。上下排列只移动完整图片区与文字区，不改变原图。纯 `presentation` 调整可复用已验收插画，但导出后仍要重新检查版式；若需要新镜头或动作，应修改视觉输入并重新生成相关图片。

拼音与汉字一一对应。标点参与排版但可无拼音；英文整句排版，不和汉字逐字硬对应。长句不能靠缩成不可读的小字解决，应调整空间或在授权范围内优化句子。

内置 PDF 若文字超出配置区域会停止并报告页面 ID，测量使用每页有效字号和所有语言。调整布局参数后重排；需要改正文含义或页数时遵守已获得的用户授权，尚未授权时由用户决策。HTML 在屏幕中随窗口宽度收缩，手机端保留可读字号并允许文字区和页面自然增高；打印恢复原物理尺寸和字号。HTML 必须在实际浏览器中检查，覆盖 320、390 像素窄屏和桌面，特别关注本机字体替换后的文字边界和长正文。不要靠隐藏溢出消除横向滚动。

封面和封底也是项目页面。没有单独标题页时，书名应出现在封面正文中；不要只设置书名元数据，却忘了页面可见书名。版权页、作者信息等按用户实际要求和真实信息排版，不能编造版权归属或出版资料。

指定文字区域后，生图前执行 `python scripts/bookcheck.py 项目/book.json --stage ready --font 实际字体路径`。它只读测量全部页面，返回每处溢出，不要求图片已完成，也不导出文件；先调整矩形再生成预留空白的图画。文字预检通过不证明留白对比度或图文位置在真实图上合适。

## 指定文字位置与无字页

艺术化单页可以用 `positioned`，插画仍完整等比显示；`image_box` 与 `text_box` 都按安全内容区左上原点的 `[左, 上, 宽, 高]` 比例填写。例如左侧短正文、右侧纵向插画：

```json
"presentation": {
  "layout": "positioned",
  "image_box": [0.40, 0.05, 0.60, 0.80],
  "text_box": [0.02, 0.35, 0.34, 0.40],
  "font_size_pt": 28,
  "text_color": "#5D4B39",
  "paper_color": "#FFF9EF"
}
```

默认拒绝有面积的图文矩形重叠。需要文字进入插画留白时，图画输入必须明确保留对应位置，并显式设置 `allow_overlap: true`；只有实际看图和成书才能确认留白是否够用。工具不检测人物像素，不能把允许叠放理解成自动保证文字不遮挡动作。

`image-only` 不保留空文字面板，完整插画占安全内容区。所有正文语言应真的为空；存在非空正文时检查器拒绝，不能默默隐藏文字。无字页仍计入已约定正文页数，前后阅读关系需人工确认。

PDF 按每页实际文字矩形测量，过长的文字或单词会指出具体页并停止。HTML 在桌面与打印中使用相同的设计矩形；640像素及以下展开为完整插画之后的正文，封面标题置前，保持可读字号与自然高度。手机的阅读布局与固定版式不同，不能仅看手机截图确认打印版式。

## 导出后检查

逐页渲染或打开检查真实文件：图像完整、无错页漏页、正文准确、拼音不碰汉字、英文与中文不重叠、文字不越界、字体无缺字、图像和文字的安全边距足够。

再检查书名、封面、正文起止、最长正文页、多角色页、场景切换页与封底，确认整书阅读顺序。文本抽取和页面计数只能证明部分结构正确，不能替代视觉检查。

将技术结果与编辑、审美结果分别判断：字体嵌入、页面数、正文匹配、无裁切或越界是技术检查；标题是否突出、翻页镜头是否服务转折、图像是否兑现正文动作、关键情绪是否可见，是人工审校。两者均有证据才报告对应项通过，不能用完整验收状态或测试覆盖率直接宣称作品高质量。

交付链接指向真实存在的文件。可编辑 HTML 与阅读 PDF按约定提供，项目数据与插画保留供后续修改。除非用户要求，避免再写一份创作过程总结。

使用 `positioned` 时另检查正文每一行是否在文字矩形内、画面留白是否与该矩形相符、字是否碰到脸部或操作道具，以及移动端展开后是否仍保留全部正文。连续小画面核对每格角色、道具状态和阅读方向；无字页从前后页核验其含义，不能只看它单独好不好看。

实际成书中逐行检查中文换行：句号、逗号、感叹号、问号和后引号不应被挤到新行开头，前引号不应孤留上一行末尾。内置测量目前只判断文字是否放得下，不自动执行中文禁则；单独一行的句末标点仍可能通过预检。优先增宽有真实留白的文字框，或重新安排明确的句子换行，保留正文含义、可读字号与图像动作。调整后重新看 PDF；HTML 因设备宽度与字体不同，另做实际显示核验。

## 印刷边界

阅读版 PDF 未自动完成 CMYK、出血、装订、嵌入字体许可或印刷厂预检。印刷任务应取得具体规格，制作并核验对应文件；不能通过修改文件名宣称可直接印刷。
